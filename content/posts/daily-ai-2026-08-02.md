## ⭐ 今日最值得关注

### 1. OpenAI 公布十项开放数学问题进展，并为每项给出 Lean 证书

OpenAI 公布了内部下一代模型 Astra 在数学与理论计算机科学上的十项结果，覆盖高维球堆积、编码理论、非 sofic 群、Connes 刚性猜想、算术电路复杂度、量子并行重复、最近向量问题、Ehrhart 体积猜想、Ramsey 数和极值图论。官方把筛选标准设为“主要结论至少十年没有进展”，并称其中多项问题在各自领域有广泛影响。

这批材料与普通基准分数不同：模型先生成数学论证，人类再与同一模型整理成论文，最后模型把每份论证形式化为 Lean 证书。OpenAI 已公开 [`ten-proofs`](https://github.com/openai/ten-proofs) 仓库和每项解题过程的模型叙述，并表示找到这些解法消耗的 token 若按 Sol API 价格计算约为 2,000 美元。

具体结论包括构造非 sofic 群、反驳一项关于群由其 von Neumann 代数唯一决定的长期猜想，以及解决 Erdős 问题 146、180 和 183。最近向量问题的多项式因子近似困难性还与后量子密码学有关。不过，Lean 证书只能说明形式化陈述在指定公理和实现下通过机器检查；这些结果的数学意义、陈述是否准确对应原问题、以及证明方法的原创价值仍需各领域研究者独立审阅。

OpenAI 也正面讨论署名问题：它认为把完全由系统生成的证明认作人类原创会误导读者，并由公司对整理和形式化的正确性负责。这使本次发布不仅是能力展示，也把“AI 生成研究结果如何署名、验证和进入学术共同体”变成了实际流程问题。

**原文金句：** “Afterward, the model formalized each argument in a Lean certificate.”
**中文：** 随后，模型把每份论证都形式化为一份 Lean 证书。

[OpenAI 原文：Ten advances in mathematics and theoretical computer science](https://openai.com/index/ten-advances-in-mathematics)

### 2. 荷兰保险合作社把 AI 推广从“买工具”改成“让员工成为构建者”

OpenAI 发布荷兰保险合作社 Univé 的企业案例。Univé 没把 ChatGPT Enterprise 当成一次普通 IT 部署，而是先让管理层统一讨论工作方式如何变化，再把认证、连接器权限继承、隐私评估、安全审查、持续监控和人工责任一起写进上线流程。

官方披露，97% 的企业许可证已激活，85% 的持证用户每周活跃，活跃用户平均每周发送 40 条提示；员工已经创建约 1,500 个内部 GPT。更关键的不是总使用量，而是组织允许员工用固定时间重做自己的工作流程，而非每个点子都先排队等待中心开发团队。

宠物保险理赔是具体例子：Workspace Agent 可先汇总理赔文件、检查兽医发票和保单条件、标出缺失信息与异常，再给理赔人员准备可追溯的建议。过去需数小时准备的案件可在数分钟内进入决策阶段，但最终判断仍由受训理赔人员负责。承保场景也采用相同分工——Agent 提前整理队列和证据，人类处理需要专业判断的部分。

这是一份厂商与客户共同呈现的案例，不是对照实验，因此效率与采用率不能直接外推到其他公司。它仍提供了一个有价值的部署信号：企业 Agent 的规模化门槛往往不是再造更多应用，而是权限能否继承、责任是否清楚、员工有没有时间把流程改造成可复用工具。

**原文金句：** “Most organisations try to scale AI by building more solutions. We chose to scale AI by creating more builders.”
**中文：** 大多数组织靠构建更多解决方案来扩大 AI；我们选择培养更多构建者。

[OpenAI 原文：Univé builds an AI-ready workforce](https://openai.com/index/unive)

## 📰 快讯

### 工具发布继续围绕 Agent 的恢复、协议兼容与成本边界补洞

过去 24 小时没有新的大模型正式发布，但三款 Agent 工具都有可核验版本更新。它们的共同点不是增加演示功能，而是修复长上下文、MCP 重连、会话恢复和调用计费等上线后才会暴露的问题。

## 🔧 工具版本

- **[oh-my-pi 17.2.3](https://github.com/can1357/oh-my-pi/releases/tag/v17.2.3)**：修复 Anthropic 订阅凭据在 1M 上下文 beta 上无条件触发 HTTP 429 的问题；OAuth 请求不再声明该 beta，订阅账户改用标准 200K 窗口。版本还修正 Codex Responses 在关闭缓存保留时仍派生 `prompt_cache_key` 的行为，并加入 ai& provider。
- **[opencode 1.18.11](https://github.com/anomalyco/opencode/releases/tag/v1.18.11)**：停止 MCP SSE 在服务器错误后陷入重连循环，兼容 `reasoning_text` 等自定义交错推理字段；桌面端外部链接改由系统浏览器打开，并修复会话标签、文件树裁切与调试栏对齐。
- **[OpenClaw 2026.7.2-beta.6](https://github.com/openclaw/openclaw/releases/tag/v2026.7.2-beta.6)**：beta 版继续强化损坏数据库后的隔离存储、SQLite 快照、跨网关重启的消息恢复、会话回退与分支，以及交互式 MCP Apps。它仍是测试版本，迁移前应完整阅读 release body，而不是按稳定版处理。
- **[Codex 0.147.0-alpha.4](https://github.com/openai/codex/releases/tag/rust-v0.147.0-alpha.4)**：过去一天连续发布 alpha.1.1、alpha.3 与 alpha.4，但 release body 只有版本号，没有可核验 changelog；这里只记录预览构建，不推测新增功能。

## 📖 今日英语

1. **open research problems（开放研究问题）**
   原句（OpenAI 数学进展）：“We also continue to evaluate our models on open research problems during development.”
   指尚无公认解答、仍由研究共同体推进的问题，常与 `open question` 互换使用。
2. **formalized each argument（形式化每份论证）**
   原句（OpenAI 数学进展）：“Afterward, the model formalized each argument in a Lean certificate.”
   `formalize` 在数学与验证语境中表示把自然语言论证改写成证明检查器可机械核验的形式。
3. **human accountability（人工责任）**
   原句（Univé）：“Enterprise authentication, connector permission inheritance, privacy assessments, governance processes, security reviews, responsible AI principles, continuous monitoring, and clear human accountability created the confidence employees needed to experiment responsibly.”
   合规文本高频搭配，强调自动系统之外仍有明确的人类责任主体。
4. **reconnect loops（重连循环）**
   原句（opencode 1.18.11）：“Stopped MCP SSE connections from getting stuck in reconnect loops after server error responses.”
   网络客户端在失败后反复连接却无法恢复时常用，通常需要退避、上限或状态重置机制。
