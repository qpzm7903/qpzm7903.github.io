## ⭐ 今日最值得关注

### Claude 把密码分析推进到“找算法本身的弱点”

Anthropic 在 [Discovering cryptographic weaknesses with Claude](https://www.anthropic.com/research/discovering-cryptographic-weaknesses) 中报告，Claude Mythos Preview 不再只寻找密码库的实现错误，而是提出了针对算法结构的新攻击。第一项工作把后量子签名候选 HAWK-256 的完整密钥恢复预估成本从 \(2^{64}\) 降到 \(2^{38}\)，等效安全强度大幅下降；HAWK 尚未部署，因此发现的价值正是赶在标准化前暴露问题。第二项工作把既有的七轮 AES-128 攻击加速约 200—800 倍，但标准 AES-128 有十轮，所以它没有攻破生产系统中的完整 AES。HAWK 方向约用 60 小时和 10 万美元 API 成本完成，AES 方向则在三天内生成数亿 token，最终累计约十亿输出 token；此后两名研究者花了数百小时验证。Anthropic 还与高校发布 CryptanalysisBench，让其他模型能在同一组密码问题上接受评测。最值得注意的结论不是“今天的加密已经失效”，而是研究瓶颈正从提出候选结果转向人类能否及时验证、披露和修复。

> **原文金句**：“Now, we have found that Claude is able to find mathematical flaws in the algorithms themselves.”
>
> 中文：现在，我们发现 Claude 能够找出算法本身的数学缺陷。

### OpenAI 的八个科学计算案例：实现变快，验证成为瓶颈

OpenAI 在 [Scientific computing in the age of agentic AI](https://openai.com/index/scientific-computing-agentic-ai) 汇总了八个以生命科学为主的 Agent 辅助软件项目，其中五个只用 Codex，三个同时使用 Codex 与 Claude Code。任务从遗留构建系统升级、性能优化，一直到语言迁移和 GPU 原生重写；例如 cyvcf2 的旧构建与打包流程被替换为现代统一方案。多个团队都观察到研究者的角色从亲自实现，转为定义目标、设计验收标准、编排迭代和审查结果。Agent 对边界清楚的小任务很有效，却无法可靠判断代码在科学上是否成立，甚至会对明显错误表现得很自信。成功案例通常依靠可测的外部标准——与旧工具精确对齐、符合预期统计性质，或在模拟数据上核对已知答案——并通过多轮小改动完成，而不是一次生成。报告同时提醒，低成本重写可能制造许多相似分叉，稀释维护者注意力，因此上游协作、归属和长期维护计划仍不可省略。对科研软件而言，AI 最先压缩的是实现成本，而不是正确性责任。

> **原文金句**：“Now, the bottleneck is validating an AI agent’s output, which still depends on human judgement.”
>
> 中文：现在，瓶颈变成了验证 AI Agent 的输出，而这仍依赖人类判断。

### Gemini 托管 Agent 加上工具钩子、预算上限与定时触发

Google 在 [Gemini API Managed Agents: 3.6 Flash, hooks, and more](https://blog.google/innovation-and-ai/technology/developers-tools/expanding-managed-agents-gemini-api-3-6-flash-hooks/) 中把 Gemini API 的托管 Agent 从“云端执行沙箱”继续推向可运营服务。默认模型切到 Gemini 3.6 Flash，也可以显式固定 3.5 Flash 或低成本的 3.5 Flash-Lite。新的环境钩子可在每次工具调用前后运行本地脚本或 HTTP 处理器：前置钩子能拒绝代码执行、文件写入等动作，后置钩子可做 lint、审计或产物验证。`max_total_tokens` 为整个多轮循环设置输入、输出与思考 token 总上限；触顶后任务以 `incomplete` 暂停并保留环境状态，可追加预算继续。定时触发器则把 Agent、环境、提示词和 cron 计划绑定为持久资源，重复运行还能沿用同一沙箱文件。免费层现已开放托管 Agent，Environments API 也能列出、检查和删除沙箱。组合起来，它解决的是生产 Agent 最朴素的三类问题：行动前能拦、花费能封顶、任务能按时跑。

> **原文金句**：“These updates turn managed agents into cost-controlled, scheduled workers that operate autonomously inside real development environments.”
>
> 中文：这些更新把托管 Agent 变成了成本可控、可定时运行，并能在真实开发环境中自主工作的执行者。

## 📰 快讯

- **[MCP 2026-07-28 规范把核心改成无状态请求/响应](https://blog.modelcontextprotocol.io/posts/2026-07-28/)**：新版取消必需的初始化握手与 `Mcp-Session-Id`，每个请求自带版本、客户端身份和能力，可落到普通轮询负载均衡器后的任意实例。它还加入多轮往返请求、列表缓存提示、发行方校验和至少 12 个月的弃用窗口；TypeScript、Python、Go、C# 一级 SDK 已同步。
- **[OlmoEarth 把洲级卫星推理压到约一天](https://huggingface.co/blog/allenai/olmoearth-infrastructure)**：Ai2 的平台把数据抓取与后处理放在 CPU、模型前向放在 GPU，并把地理区域切成可重入、幂等的分区任务。一次北美野火风险图峰值并行使用约 19,600 个 CPU 与 994 个 GPU，把预估 4,737 小时串行计算压到 30.5 小时，约 155 倍加速；官方称洲级任务每平方公里成本低于一美分。
- **[Liquid AI 发布两款 LFM2.5 长上下文编码器](https://huggingface.co/blog/LiquidAI/lfm2-5-encoders)**：230M 与 350M 模型支持 8,192 token，可用于分类、路由、政策检查与个人信息识别。官方测试中 230M 模型在 8K 输入的 CPU 前向约 28 秒，ModernBERT-base 超过 90 秒，约快 3.7 倍；两款权重与评测结果均已开放。
- **[OpenAI 开源 Codex Security CLI 与 TypeScript SDK](https://github.com/openai/codex-security)**：工具可扫描仓库、审查变更、跟踪漏洞并接入 CI，也能通过 SDK 对目录执行检查并取得报告路径。README 明确要求 Node.js 22+、Python 3.10+，且仍需 Codex Security 访问权限，开源客户端不等于服务无需授权。

## 📖 今日英语

- **under consideration** — Anthropic 原句：“HAWK is one of the third-round candidates under consideration from this call.” 释义：正在审议、考虑之中。为什么值得记：标准化、招聘和政策流程中都常用于表示尚未最终采用。
- **scientifically valid** — OpenAI 原句：“Agents handled specific, well-scoped requests effectively but could not reliably judge whether their work was scientifically valid or met expectations.” 释义：在科学上成立。为什么值得记：它比“代码能运行”多了一层方法与结论的有效性要求。
- **runaway tasks** — Google 原句：“To prevent runaway tasks, you can pass `max_total_tokens` inside `agent_config` to cap total consumption.” 释义：失控、持续消耗资源的任务。为什么值得记：描述 Agent 循环、进程和云成本失控时非常实用。
- **stateless protocol core** — MCP 原句：“The highlight of this release is a stateless protocol core.” 释义：无状态协议核心。为什么值得记：`stateless` 是 HTTP、微服务和横向扩容中的高频架构词。
