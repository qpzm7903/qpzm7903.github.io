## ⭐ 今日最值得关注

### 1. 腾讯混元 UniRL 把图像编辑接入训练侧 GRPO

腾讯混元的 UniRL 主分支在 8 月 2 日合入一项可核验的实质更新：为 HunyuanImage 3 图生图编辑加入训练侧 GRPO 配方。GRPO 是一类强化学习方法，会让模型生成多组候选，再依据奖励比较并更新；这里的奖励来自远端 EditReward 服务，对“源图—编辑图”成对打分。

这次提交不是只加一份示例配置：共改动 852 行、删除 149 行，新增 229 行的 `hi3_it2i.yaml`，并修改扩散采样、条件编码、VAE 解码、随机种子和训练器。代码把训练设成单引擎路径，让 rollout 直接复用正在训练的模型；为让采样和 replay 在第一次更新时真正对齐，配方关闭扩散 KV cache，并在训练阶段把 guidance scale 设为 1。

提交还为每个请求、样本和 SDE 步骤派生独立随机数生成器，目标是在不把所有候选锁成同一噪声的前提下实现可复现。多卡路径也补了防护：每个数据并行 rank 独立解码自己持有的样本，避免 HunyuanImage 3 的默认跨卡 VAE 路径只在 rank 0 留下结果。它仍是主分支训练能力，不等同于新模型权重或正式版本发布；价值在于图像编辑强化学习从路线图变成了有配置、有实现细节的代码。

**原文金句：** “Request-local RNG helpers for reproducible HI3 trainside sampling.”
**中文：** 面向可复现 HI3 训练侧采样的请求级局部随机数工具。

## 📖 今日英语

1. **reproducible sampling（可复现采样）**
   原句（UniRL 提交）：“Request-local RNG helpers for reproducible HI3 trainside sampling.”
   训练和评测需要在相同种子下重现结果时常见，通常要避免多个样本意外共享同一随机流。
2. **layered long-term memory（分层长期记忆）**
   原句（TencentDB Agent Memory）：“TencentDB Agent Memory = symbolic short-term memory + layered long-term memory.”
   强调记忆按抽象层次组织，而不是把所有片段平铺进一个向量库。
3. **full traceability（完整可追溯性）**
   原句（TencentDB Agent Memory）：“Full traceability and lossless recovery.”
   在记忆、审计和证据系统中，表示能从摘要一路回查到底层原始材料。
4. **stream idle timeout（流空闲超时）**
   原句（oh-my-pi 17.2.4）：“Fixed direct Anthropic provider streams ignoring `model.compat.streamIdleTimeoutMs`.”
   指流式响应两次事件之间允许等待的时长；长推理模型常需要比默认值更宽的看门狗窗口。
