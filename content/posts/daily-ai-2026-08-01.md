## ⭐ 今日最值得关注

### 1. DeepSeek-V4-Flash 正式版进入公测：重做后训练，原生接入 Responses API

DeepSeek 在 7 月 31 日把 DeepSeek-V4-Flash 正式版 API 开放为 public beta，调用方式不变，只需把模型名设为 `deepseek-v4-flash`。这不是更换架构或扩大参数量：官方明确说 0731 版与 Preview 保持相同架构和规模，只重新做了 post-training（后训练），因此这次更新更像是把重点放在 Agent 行为和工具使用上。

官方列出的公开成绩包括 Terminal Bench 2.1 的 82.7、NL2Repo 的 54.2、Cybergym 的 76.7、DeepSWE 的 54.4，以及 Toolathlon verified 的 70.3。官方同时提醒，代码 Agent 公共基准使用尚未发布的 DeepSeek Harness minimal mode、max effort、`top_p=0.95` 和 `temperature=1.0`，这些条件必须与分数一起看，不能直接当作所有部署环境的保证。

工程接入方面，正式版原生支持 Responses API，并专门适配 Codex；现有 DeepSeek API 用户不必更换 base URL。此次只升级 V4-Flash API，V4-Pro API 与 App/Web 模型都没有变化，V4-Pro 正式版则仍标为“即将推出”。对开发者最重要的信号是：国产模型的竞争点正在从单轮问答，进一步转向可直接嵌入编码 Agent 的协议兼容、工具调用和长流程执行。

**原文金句：** “DeepSeek-V4-Flash-0731 keeps the same model architecture and size as DeepSeek-V4-Flash-Preview, and was only re-post-trained.”
**中文：** DeepSeek-V4-Flash-0731 与预览版保持相同架构和规模，只重新进行了后训练。

[DeepSeek 官方 Change Log：DeepSeek-V4-Flash Update](https://api-docs.deepseek.com/updates/#date-2026-07-31)

### 2. OpenAI 拆解柬埔寨诈骗网络：AI 同时参与引流、话术、伪造材料与内部运营

OpenAI 公布一次针对柬埔寨诈骗网络的处置。线索最初来自 WhatsApp，调查显示该网络用 ChatGPT 支持投资、恋爱、赌博和冒充执法机关等多类骗局，而不是只运行一种固定脚本。

账号被用于创建虚假人物、生成和翻译与受害者的消息、制作推广材料，也用于内部公告、员工沟通和日常管理。行动模式通常从建立信任开始，再引入虚假投资或奖金，最后要求受害者支付激活费、罚款或入金，并上传转账截图。部分对话还涉及招聘、债务、扣薪、拘禁和逃跑，呈现出网络诈骗与人口贩运、强迫劳动相互交叠的风险；OpenAI 也明确说，无法据这些对话独立判断每个涉事者的具体处境。

OpenAI 已封禁相关账号，把威胁指标分享给行业伙伴和有关机构，并采取措施提高重新接入难度。官方估计该网络可能接触了数百名目标，但没有独立验证聊天中提到的个人损失数字。这份案例的价值在于展示了生成式 AI 在犯罪组织中的真实位置：它不是自动完成整个骗局，而是横跨获客、语言本地化、素材制造和后台管理，降低了同时经营多种骗术的成本。

**原文金句：** “The network used our models to create and support the operation of fake online personas, generate and translate messages sent to scam targets, create promotional content for their fraudulent schemes, and assist with day-to-day operations.”
**中文：** 该网络用模型创建并运营虚假网络身份、生成和翻译诈骗消息、制作推广内容，并辅助日常运营。

[OpenAI 原文：Disrupting a Criminal Scam Operation](https://openai.com/index/disrupting-malicious-uses-of-ai-criminal-scam-operation)

## 📰 快讯

### OpenAI 解释“充裕智能”的商业闭环

OpenAI 把降价、模型能力、基础设施和真实需求描述成一套反馈循环：更强模型推动采用，采用带来收入和需求信号，再支持下一轮研究与算力投资。官方披露模型已覆盖逾 10 亿活跃用户和逾 200 万家企业，并强调衡量标准不应只是 token 单价，而应包括重试、监督、错误和时间在内的“成功结果成本”。

[OpenAI 原文：Building abundant intelligence](https://openai.com/index/building-abundant-intelligence)

### OpenAI 对照欧盟 AI 法案公开治理与内容溯源做法

随着欧盟 AI 法案进入下一阶段，OpenAI 汇总其系统卡、红队、Preparedness Framework 与第三方评测等治理工具。内容溯源方面采用 C2PA Content Credentials 与 SynthID 的分层方案，并计划从图像扩展到音频和更多模态；官方也承认元数据可能丢失、标签可能无法跨平台传递，单一信号并不完美。

[OpenAI 原文：Advancing responsible AI across Europe](https://openai.com/index/advancing-responsible-ai-across-europe)
