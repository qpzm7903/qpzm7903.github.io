# 重写 JSON-LD 模板并程序化生成 366 篇摘要（不再让模板猜摘要）

## 背景

基线（P0）实测，元数据层是"有，但错"：

| 指标 | 值 |
|---|---|
| `<html lang>` / JSON-LD `inLanguage` | `en` / `en`（内容是中文） |
| `description` 覆盖率 | 9 / 366 |
| 文章页 HTML 中位 | 38,544 B；`HTML/Markdown` 中位 **7.23×** |
| JSON-LD | `articleBody` 塞全文、`author.name` 双重嵌套、`wordCount=477`（中文按空格断词） |
| og:image / twitter:image | 均无 |

根因有两个：一是 `languageCode` 单独设置时 Hugo 的 `site.Language.Lang` 仍回退为 `en`；
二是 PaperMod 的 `templates/schema_json.html` 把 `.Content | plainify` 塞进 `articleBody`，
同时用 `.Summary` 充当 `description`——而 `.Summary` 对本站是正文前 70 词，产出
`"📰 科技热点日报 | 2026-06-03 Generated by OpenClaw v3"` 这类垃圾摘要。

## 决策

1. `hugo.yaml` 改用 `locale` + `defaultContentLanguage` + `languages.zh-cn.label`
2. **覆盖** `layouts/partials/templates/schema_json.html`：删 `articleBody`、删 `wordCount`、
   修 `author`、补 `image`/`url`、`inLanguage` 取 `site.Language.Lang`
3. **程序化生成摘要**（`scripts/gen-descriptions.py`），按内容家族取候选，写回 front matter；
   默认不覆盖手写描述（9 篇）
4. **生成默认 OG 图**（`scripts/gen-og-image.swift`，CoreGraphics，1200×630 JPEG 63KB）
   并经 `params.images` 接线，四处（og/twitter/JSON-LD）同源
5. 新增 `scripts/verify-meta.sh`：把上述每一条变成可执行断言（含可选 vnu 0 error）

## Considered Options

- **A. 在模板里实时截断 `.Summary`（设置 summaryLength）**：被否。`summaryLength` 只影响
  `.Summary` 的词数，不解决"摘要内容本身是模板垃圾"的问题；且每次都靠模板猜，无法评审。
- **B. 用 LLM 逐篇生成摘要**：被否（本阶段）。366 次调用不可复现、不可评审，且违反"不改写正文"的边界感；
  程序化抽取虽然朴素，但规则可读、可 diff、可回退。
- **C. 保留 `articleBody`（有人说利于富结果）**：被否。`BlogPosting` 的 `articleBody` 不是 Google 富结果必需字段，
  代价是每页体积翻倍（中位 38.5KB → 22.3KB 的降幅主要来自此项）。
- **D. 保留 `wordCount`**：被否。`.WordCount` 对 CJK 按空格断词，输出错误数据比不输出更糟。
- **E. fork 整个主题 `head.html` 以彻底去掉重复 robots/自定义 description**：被否（本阶段）。
  只覆盖 `schema_json.html` 一个文件，升级冲突面积最小；`head.html` 里的 description 已在
  front matter 层面修正（有真 description 即用），无需改模板。
- **F. 手工做一张 OG 图**：被否。图片是元数据的一部分，必须可复现；脚本生成保证改标题/配色可重跑。

## Consequences

- **正面**：文章页 HTML 中位 **38,544 → 22,260 B（-42%）**，`HTML/MD` 中位 **7.23 → 3.41**；
  `description` 覆盖 **9 → 366**；`lang`/`inLanguage` 正确；`og:image`/`twitter:image`/JSON-LD `image` 齐备；
  `verify-meta.sh` 6 项全绿，vnu **0 error**。
- **代价 / 风险**：
  1. 自动摘要可读但非"人写"，个别篇目偏弱（周报、WSL2 指南），列入内容待办；
  2. `schema_json.html` 成为覆盖文件，主题升级需比对（见 `docs/meta-policy.md` §3、§6.5）；
  3. `<script>` 上下文必须 `jsonify | safeJS`，否则出现 `"\"值\""` 二次引号（本次踩坑，已写入模板注释）。
- **可逆**：删除覆盖文件即回到主题行为；摘要可用 `git revert` 一次性回退（脚本幂等，可重跑）。
- **未覆盖**：vnu 的 4128 条 `aria-hidden` warning 来自主题 SVG；18 个列表页缺 h1——都需改主题模板，留给 P4/P6。
